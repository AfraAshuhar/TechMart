# 🛒 TechMart – Electrical Products E-Commerce Website

TechMart is a web-based e-commerce platform developed to make purchasing electrical products easier and more convenient. It provides customers with an online shopping experience and administrators with product and order management features.

## 🚀 Technologies Used

- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** PHP, Laravel
- **Database:** MySQL
- **Build Tool:** Vite

## ✨ Key Features

- Browse electrical products
- View individual product details
- Browse products by category
- Search for products
- Add products to shopping cart
- Customer checkout
- Order management
- Admin dashboard
- Product management
- Category management
- Blog functionality
- Product reviews

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/AfraAshuhar/TechMart.git
```

### 2. Navigate to the project directory

```bash
cd TechMart
```

### 3. Install PHP dependencies

```bash
composer install
```

### 4. Install frontend dependencies

```bash
npm install
```

### 5. Configure environment variables

```bash
cp .env.example .env
```

Configure your database details in the `.env` file.

### 6. Generate application key

```bash
php artisan key:generate
```

### 7. Run database migrations

```bash
php artisan migrate
```

### 8. Start the development servers

```bash
php artisan serve
```

In another terminal:

```bash
npm run dev
```
